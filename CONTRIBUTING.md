# External Contribution Policy

[Repository home](README.md) · [License](LICENSE) · [Design authorship](AUTHORS.md)

CGX 1 does **not** accept external contributions.

Pull requests, issues, discussions, unsolicited patches, feature submissions, and community-maintained changes are not part of this repository's development model. The public repository exists so the design, documentation, source, CAD, calculations, and validation work can be inspected, studied, cloned, and reused under the MIT License.

## Forks and derivative work

The [MIT License](LICENSE) permits independent forks, modifications, redistribution, and derivative work subject to its terms.

A fork or derivative project is maintained independently. It is not an official CGX 1 revision and should not imply endorsement, review, validation, or maintenance by Brandon Connell unless that relationship is explicitly stated.

## Changes to CGX 1

The maintained CGX 1 repository is updated by its design engineer. External pull requests are not accepted.

If you independently discover a serious private security problem that could affect future firmware, drivers, update logic, or hardware control, report it using the contact method in [SECURITY.md](SECURITY.md). A report does not imply that an external patch will be accepted.

For engineering or work inquiries, see [AUTHORS.md](AUTHORS.md).
