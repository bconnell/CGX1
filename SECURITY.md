# Security

[Documentation index](docs/README.md) · [Repository integrity](docs/REPOSITORY_INTEGRITY.md)

CGX 1 does not use public GitHub Issues or Discussions for security reports.

Do not publish credentials, private keys, access tokens, signed URLs, private machine paths, exploit details, or other confidential material in public forks or redistribution packages.

The current repository is an engineering design package. It does not contain a production updater, network service, credential store, or shipping driver.

If you discover a serious private security concern that could affect future firmware, drivers, update logic, or hardware control, contact:

**Brandon Connell**  
[brandon@brandonconnell.com](mailto:brandon@brandonconnell.com)

Security reports are welcome as private notifications. External patches and pull requests are not accepted.

GitHub and LinkedIn contact information are also listed in [AUTHORS.md](AUTHORS.md).
